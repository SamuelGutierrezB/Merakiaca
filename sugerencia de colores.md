# Paleta de colores para Merakiaca

Basándome en los colores proporcionados y en el significado del nombre "Merakiaca" (alma, creatividad y amor), he desarrollado una paleta armónica para un sitio web de catálogo y e-commerce de cojines herbales.

## Paleta principal

He ajustado ligeramente los tonos para lograr una mejor armonía visual y accesibilidad web:

### Colores primarios

1. **Azul Alma** - `#2391C3` (azul original, ligeramente ajustado)

   - Color principal: transmite calma, confianza y serenidad
   - Uso: encabezados, botones principales, elementos destacados

2. **Rojo Pasión** - `#D7322D` (rojo original)

   - Color secundario: representa energía, amor y vitalidad
   - Uso: botones de acción, precios, elementos importantes

3. **Amarillo Creatividad** - `#F5E63C` (amarillo original)

   - Color terciario: simboliza creatividad, alegría y calidez
   - Uso: destacados, elementos decorativos, llamadas a la acción

### Colores neutrales

4. **Negro Profundo** - `#000005` (negro original)

   - Para texto y elementos de alto contraste
   - Uso: títulos, texto principal, bordes

5. **Púrpura Espíritu** - `#8A4A86` (púrpura original ajustado para mejor contraste)

   - Representa espiritualidad y bienestar
   - Uso: elementos secundarios, iconos, detalles

### Colores complementarios

6. **Verde Natural** - `#4A9E7C` (nuevo - inspirado en la naturaleza herbal)

   - Representa lo natural, salud y frescura
   - Uso: etiquetas "natural", categorías de productos, iconos

7. **Beige Terroso** - `#E8DFCA` (nuevo - neutral cálido)

   - Color de fondo complementario
   - Uso: fondos, tarjetas de producto, áreas secundarias

## Aplicación sugerida para el sitio web

### Esquema general

- **Fondo principal**: Blanco o `#F9F9F9` (gris muy claro)
- **Texto principal**: `#000005` (negro profundo)
- **Encabezados**: `#2391C3` (azul alma) o `#000005`
- **Enlaces y botones principales**: `#2391C3` (azul) → `#1A6B8E` (hover)
- **Botones secundarios/acción**: `#D7322D` (rojo pasión) → `#B32824` (hover)
- **Elementos destacados**: `#F5E63C` (amarillo creatividad)
- **Bordes y separadores**: `#E8DFCA` (beige terroso)

### Para el catálogo de productos

- **Fondo tarjetas de producto**: Blanco o `#F9F9F9`
- **Borde tarjetas**: `#E8DFCA` (beige terroso)
- **Precios**: `#D7322D` (rojo pasión)
- **Etiquetas "natural/herbal"**: `#4A9E7C` (verde natural) sobre fondo claro
- **Categorías**: `#8A4A86` (púrpura espíritu)

## Accesibilidad y contraste

Esta paleta cumple con los estándares de contraste WCAG:

- Texto negro (`#000005`) sobre fondo claro: ✓ Excelente contraste
- Azul (`#2391C3`) sobre blanco: ✓ Contraste adecuado
- Rojo (`#D7322D`) sobre blanco: ✓ Contraste adecuado (evitar para texto largo)
- Amarillo (`#F5E63C`) sobre blanco: ✗ Bajo contraste (usar solo para elementos no textuales)

## Psicología de colores aplicada

- **Azul**: Transmite confianza, calma y seriedad (ideal para un e-commerce)
- **Rojo**: Estimula acción y pasión (perfecto para botones de compra)
- **Amarillo**: Evoca creatividad y energía (coincide con el concepto "meraki")
- **Verde**: Conecta con la naturaleza y productos herbales
- **Púrpura**: Sugiere espiritualidad y bienestar

Esta paleta equilibra profesionalidad (azul), acción (rojo), creatividad (amarillo) y conexión con la naturaleza (verde), perfecta para un emprendimiento de cojines herbales que busca transmitir alma, creatividad y amor.
